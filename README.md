# وتر — Android APK

هذا المشروع يحول ملف HTML المرفوع إلى تطبيق Android باستخدام WebView.

## البناء من الهاتف فقط عبر GitHub Actions

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى المستودع، بما فيها مجلد `.github`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build APK**.
5. اضغط **Run workflow** ثم اضغط **Run workflow** مرة أخرى.
6. انتظر حتى تنتهي عملية البناء بنجاح.
7. افتح عملية البناء المكتملة، وانزل إلى **Artifacts**.
8. نزّل `watar-apk`، ثم فك ضغطه في الهاتف.
9. افتح `app-debug.apk` وثبّته.

> هذا هو Debug APK، وهو قابل للتثبيت على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.
